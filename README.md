# Airline Booking & Management System

Учебный проект на Java: бронирование авиабилетов, управление рейсами, тестовая оплата, отмена, возвраты и check-in. Основная цель — понять и уметь объяснить Java, ООП, работу с БД и транзакциями.

**Текущий статус:** подготовлена спецификация редакции 3 и схемы. Код приложения, Maven-конфигурация и миграции ещё не созданы; команды запуска появятся после их проверки.

## Основные решения

Java 21, один Spring Boot backend, PostgreSQL, простой HTML/CSS/JS интерфейс. Точные совместимые версии библиотек будут закреплены при создании каркаса.

Все пассажиры — от 18 лет, до 9 человек в заказе. Вылеты вымышленные, платежи симулируются, валюта KZT. Нет детских тарифов, сопровождения, настоящих платежей и внешних расписаний. Все операции с местами одного рейса согласуются блокировкой строки рейса в БД.

Ближайший этап — создание каркаса, миграций и первых небольших Java-классов с объяснением и тестами. Локальный запуск на компьютере будет подготовлен вместе с рабочей реализацией.
